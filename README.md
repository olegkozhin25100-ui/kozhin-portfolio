# Олег Кожин — портфолио

Минималистичное портфолио видеомонтажёра. Молочная бумага, крупная типографика, асимметричная подборка работ. Адаптация для телефона, фильтры, архив из 18 видео и доступный видеоплеер.

## Запуск

Откройте `index.html` или запустите `python3 -m http.server 8765` из папки сайта.

Сборка и установка зависимостей не нужны. GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

## Контент

- Тексты, цены и контакты взяты с публичного сайта https://kozh1n-oleg2510.wfolio.pro/ 11 октября 2026 года.
- Все 18 роликов сохранены в архиве. Названия — описательные подписи к кадрам, а не официальные названия заказов.
- Обложки и портрет лежат рядом с `index.html`. Видеофайлы загружаются по исходным адресам Wfolio только после нажатия. Для работы этих ссылок нужны доступные файлы на Wfolio; перед отключением Wfolio перенесите видео на другое хранилище и замените адреса в `index.html`.
- Дизайн вдохновлён сайтом ко дню рождения Алины. Личные фотографии и тексты из него не используются.

## Редактирование

`index.html` — контент, цены, контакты и ссылки на видео. `style.css` — оформление и мобильные размеры. `script.js` — фильтры, архив и видеоплеер.
